# Room photo credits

Every photo in this folder is named after its room (`cosy-single.jpg`, ...) and
listed here with its author, source page and license.

Responsive `-640.webp` and `-1200.webp` variants are derived from each JPEG
(WebP quality 82, method 6). The original JPEGs remain available for the API seed
and future re-exports; the web demo serves the responsive WebP versions.
